# ChatBI 人工 UAT 测试样例

测试日期：2026-06-08  
测试入口：`http://127.0.0.1:5174/`  
运行模式：Real

## 1. 测试说明

请按顺序执行以下用例。每个用例重点检查：

- 回答是否正常完成，没有显示“工作流已中断”。
- 消息上方显示的 Skill 中文名称是否正确。
- 思考与执行过程是否逐步出现，并在答案开始输出后自动收起。
- 展开思考过程后，节点入参、出参、耗时和复制按钮是否可用。
- 包含数值表格的回答是否正常展示表格与 ECharts 图表。
- 新会话是否使用首个问题自动命名，历史会话是否可以置顶、重命名和删除。

## 2. 核心测试用例

### UAT-01 普通问答

联网搜索：关闭

```text
汽车保养一般多少公里做一次？请简要回答。
```

预期结果：

- Skill 显示“智能问答”。
- 回答包含常见保养公里数或时间建议。
- 不调用数据库或联网检索。

### UAT-02 内部数据查询

新建对话，联网搜索：关闭

```text
2023年6月中东公司的销量（包括批发量和终端量）是多少？
```

预期结果：

- Skill 显示“数据查询与分析”。
- 思考过程包含知识检索、N2SQL、SQL 执行和数据解读。
- 数据表包含：
  - 批发量：`2160`
  - 终端量：`2311`
- 页面展示数据表格与图表。

### UAT-03 同比分析

新建对话，联网搜索：关闭

```text
2023年6月中东公司终端量同比去年怎么样？
```

预期结果：

- Skill 显示“同环比分析”。
- 本期终端量为 `2311`，去年同期为 `0`。
- 去年同期为零时，不应生成误导性的同比百分比。

### UAT-04 跨表多指标查询

新建对话，联网搜索：关闭

```text
2023年6月中东公司的批发量和产量分别是多少？
```

预期结果：

- Skill 显示“数据查询与分析”。
- SQL 执行成功，不出现 `scheduling_qty` 字段错误。
- 数据表包含：
  - 批发量：`2160`
  - 产量：`1933`

### UAT-05 联网开关关闭拦截

新建对话，联网搜索：关闭

```text
网上搜索最近的中东汽车市场趋势，并简要总结。
```

预期结果：

- 不执行联网检索。
- 页面提示需要先开启联网搜索。

### UAT-06 联网公开信息问答

保持当前对话，开启联网搜索后，再次发送：

```text
网上搜索最近的中东汽车市场趋势，并简要总结。
```

预期结果：

- Skill 显示“联网检索问答”。
- 思考过程包含联网检索节点。
- 回答包含公开市场信息和来源链接。

### UAT-07 内部数据与联网综合分析

新建对话，联网搜索：开启

```text
查询广汽国际2023年6月中东公司的销量，并对比公开市场信息进行分析。
```

预期结果：

- Skill 显示“内部数据与联网分析”。
- 思考过程同时包含 N2SQL、SQL 执行和联网检索。
- 内部数据包含批发量 `2160`、终端量 `2311`。
- 最终回答区分内部数据事实与外部公开信息。

### UAT-08 多轮追问与上下文复用

紧接 UAT-07，在同一个对话中发送：

```text
和其他竞品相比表现如何？请继续分析。
```

预期结果：

- Skill 显示“联网对比分析”。
- 回答复用上一轮内部数据。
- 本轮应联网检索，但不应重复执行内部 SQL 查询。

### UAT-09 隐式全球市场问题

新建对话，联网搜索：开启

```text
广汽国际2023年在全球市场卖得怎么样？请结合公开市场信息分析。
```

预期结果：

- Skill 显示“内部数据与联网分析”。
- 即使没有直接说“网上搜索”，也应同时调用内部数据和联网检索链路。

## 3. 页面交互检查

完成上述问题后，检查：

| 响应式布局 | 缩窄窗口后页面无横向溢出 |
