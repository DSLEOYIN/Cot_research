## 7. 2026-06-05 复测更新

用户指出 npm 可由 Codex 自行安装后，本轮已在项目内临时解出 npm runtime，不修改系统目录：

```bash
mkdir -p .system_generated/npm-runtime
curl -L https://registry.npmjs.org/npm/-/npm-10.9.2.tgz -o .system_generated/npm-runtime/npm.tgz
tar -xzf .system_generated/npm-runtime/npm.tgz -C .system_generated/npm-runtime
```

由于当前 `node` 来自 `Codex.app`，直接使用 Rollup native 可选依赖时触发 macOS 代码签名限制，因此前端工程将 `rollup` 覆盖为 wasm 版本：

```json
"rollup": "npm:@rollup/wasm-node@^4.27.1"
```
