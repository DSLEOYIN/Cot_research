# 工作流节点配色设计

## 目标

将思考过程中的工作流节点从单调灰色调整为清爽蓝绿配色，提升状态辨识度和视觉层次。

## 设计

- 完成态使用薄荷绿背景、青绿色边框与图标。
- 运行态使用浅蓝背景、品牌蓝边框与图标，并保留现有动画。
- 失败态使用浅红背景、玫红边框与图标。
- 标题、说明和耗时随状态使用协调色；节点布局、交互与详情展开行为保持不变。
- 节点增加轻边框，悬停时轻微提亮，避免大面积灰色和过强视觉噪音。

## 验证

- CSS 合约测试覆盖三种状态的背景、边框和文字配色。
- 前端 TypeScript 构建通过。
- 在真实 ChatBI 页面检查节点可读性及整体协调性。
